1. File Report

Register detailed metadata, room/hall location, serial hints, and upload photos.

2. Intelligent Matching

3. Ownership Claim

Claimants submit proof (invoices, matching serial numbers, or identifying marks) for review.

4. Verified Handover

Security authority conducts physical verification, issues signed certificate, and closes ticket.
